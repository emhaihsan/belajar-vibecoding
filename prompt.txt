buatkan API untuk registrasi get user saat ini yang sedang login

Endpoint: POST /api/user/current

Headers:

- Authorization: Bearer <token> (token adalah token yang ada di table user)



Response Body Success:
{
    "data": {
        "email": "user@example.com",
        "name": "John Doe"
    }
}

Response Body Error (user tidak terdaftar):
{
    "status": "error",
    "error": "User tidak terdaftar"
}
